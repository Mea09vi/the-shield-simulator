🚢 PV SEARCH PATTERN CONFIGURATION
▸ BARRIER PATROL
PV ลาดตระเวนในแนวกั้น (Barrier Line) ตามทิศที่กำหนด เหมาะสำหรับ ปิดกั้นเส้นทางเข้า สู่พื้นที่ UDC จากทิศทางที่ทราบ — ประสิทธิภาพสูงสุดเมื่อทิศภัยคุกคามชัดเจน
L = ความยาวแนวกั้น (nm)
D = Track Spacing (nm)
T = L / speed × crossings
Pb = 1 − e^(−W/D) · Coverage
📖 NWP 3-21.2M · IAMSAR Vol.II Sec.5
▸ EXPANDING SQUARE
เริ่มจาก Datum Point แล้วขยายออกรอบทิศ ทุกๆ 2 ขา — ใช้เมื่อต้องการค้นหา
รอบ UDC โดยไม่ทราบทิศภัยคุกคาม หรือต้องการ area denial รอบจุดกำหนด
S = Track Spacing (nm)
Leg k: length = ⌈k/2⌉ × S
N legs → Total: N/2·(N/2+1)/2 × S
Bearing: N→E→S→W (repeat)
📖 Naval Ops Analysis 3rd Ed. §8.4
▸ PARALLEL SWEEP
กวาดพื้นที่อย่างเป็นระบบด้วยเส้นทางขนาน (Creeping Line) ใช้เมื่อต้องการ coverage สูงสุด ในพื้นที่ corridor กว้าง — systematic exhaustive search
C = Corridor Width (nm)
S = Track Spacing (nm)
n = ⌈C / S⌉ passes
POD = 1 − e^(−W·n/C)
📖 IAMSAR Vol.II §5.3 · USCG Pub.

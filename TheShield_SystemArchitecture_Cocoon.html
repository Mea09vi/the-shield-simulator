สีของเส้น (= โมดูลประมวลผลปลายทาง): ① จำลองภัยคุกคาม ② สมุทรศาสตร์/สมการโซนาร์ ③ หลบหลีกสิ่งกีดขวาง·3D ④ AI ประเมินผล ⑤ ฝ่ายเสนาธิการ AI ⑥ จอ C2 / NCO กำลังรบ: ● มีประจำการแล้ว ◆ ต้องการจัดหา 🖱 ชี้ที่กล่อง เซนเซอร์ / โมดูล / กำลังรบ เพื่อเน้นเส้นเชื่อมโยง  ·  เส้นประทอง = ลำดับเรื่อง ①→⑥
เส้นทางสำคัญของระบบ (KEY THREADS) — อ่านผังนี้อย่างไรให้เห็นความเชื่อมโยง
สายสมุทรศาสตร์ → ระยะโซนาร์WOA23 + CTD/MBES (เรือสำรวจ อศ.) + ADCP + น้ำขึ้น-ลง → ② สมการโซนาร์ SE = SL − 2TL + TS − (NL − DI) − DT → กำหนด ระยะตรวจจับจริง ของ Seabed Sentry / Guardian UUV / ฮ.MH-60S / โซนาร์เรือ
สายภัยคุกคาม → การตอบโต้Seabed Sentry + DAS + โซนาร์ + AIS/Dark Vessel → ① จำลองภัยคุกคาม → ④ AI ประเมิน → ⑤ ฝ่ายเสนาธิการ AI (IPOE→ECOA→COA) → ⑥ จอ C2 → สั่งใช้ PV / ฮ. / ESSM / C-UAS / Copperhead / Trap-Mine (ปิด kill-chain: ตรวจจับ→ประเมิน→วางแผน→ตอบโต้)
สายความสมจริงGEBCO/แผนที่เดินเรือ + MBES → ③ Land/Depth mask — ตัดปัจจัยการวางเรือบนพื้นบก · เส้นทางเลี่ยงน้ำตื้น-แนวปะการัง · ภาพสามมิติ three-geo ทำให้ผลการจำลองน่าเชื่อถือ
สาย Network-Centric (NCO)track ทุกโดเมน (ใต้น้ำ/ผิวน้ำ/อากาศ/อวกาศ/ไซเบอร์-EM/ชายฝั่ง + AI/Decision = โดเมนที่ ๗) หลอมรวมขึ้น ⑥ จอเดียว RMP/COP ที่ ศปก.ทร. — ทุกหน่วยกำลังเห็นภาพเดียวกัน สั่งการบนข่ายเดียวกัน
สายการจัดหา (GAP → จัดหา)ขีดความสามารถใต้น้ำที่ยังขาด → รายการจัดหา ◆ แคปซูล UDC · Guardian UUV · Copperhead · Seabed Sentry · สาย DAS · Trap-Mine — ผังแสดงว่าแต่ละรายการอุดช่องว่างโมดูลใด
